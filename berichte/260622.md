# 1. Übung (GNU Debugger)

## 1.1 Breakpoint setzen und disassemblieren

```assembly
(gdb) b main
Breakpoint 1 at 0x555555557172: file ./pwcheck.cpp, line 27.
(gdb) run

Breakpoint 1, main () at ./pwcheck.cpp:27
(gdb) disas
Dump of assembler code for function main():
   0x0000555555557160 <+0>:    push   %rbp
   0x0000555555557161 <+1>:    mov    %rsp,%rbp
   ...
   0x00005555555571a2 <+66>:   cmp    $0x0,%eax
   0x00005555555571a5 <+69>:   je     0x55555555723d <main()+221>
   ...
End of assembler dump.
```

| Befehl  | Beschreibung                                      |
|---------|---------------------------------------------------|
| `b main` | Setzt einen Breakpoint am Anfang von `main`       |
| `run`    | Führt das Programm bis zum Breakpoint aus         |
| `disas`  | Gibt den aktuellen Funktionsbereich als Assembly aus |

---

## 1.2 Jump-Adresse identifizieren

```assembly
0x00005555555571a5 <+69>:   je     0x55555555723d <main()+221>
```

Dieser `je`-Befehl springt zum Fehlerfall (falsches Passwort). Er belegt 6 Bytes und muss durch `nop`-Instruktionen (`0x90`) ersetzt werden.

---

## 1.3 `je` → `nop` patchen

```assembly
(gdb) set {unsigned char}0x00005555555551a5 = 0x90
(gdb) set {unsigned char}0x00005555555551a6 = 0x90
(gdb) set {unsigned char}0x00005555555551a7 = 0x90
(gdb) set {unsigned char}0x00005555555551a8 = 0x90
(gdb) set {unsigned char}0x00005555555551a9 = 0x90
(gdb) set {unsigned char}0x00005555555551aa = 0x90
```

Alle 6 Bytes des `je`-Befehls werden mit `0x90` (NOP) überschrieben. Dadurch wird die Passwortprüfung übersprungen.

# 2. Übung (add zu sub patchen)

## 2.1 Ziel-Instruktion identifizieren

```assembly
0x0000555555555224 <+196>:   add    -0xc(%rbp),%eax
```

Der `add`-Opcode an dieser Adresse soll durch `sub` (`0x2b`) ersetzt werden.

---

## 2.2 Passwortcheck umgehen + `add` → `sub` patchen

```assembly
(gdb) set {unsigned char}0x00005555555551a5 = 0x90
(gdb) set {unsigned char}0x00005555555551a6 = 0x90
(gdb) set {unsigned char}0x00005555555551a7 = 0x90
(gdb) set {unsigned char}0x00005555555551a8 = 0x90
(gdb) set {unsigned char}0x00005555555551a9 = 0x90
(gdb) set {unsigned char}0x00005555555551aa = 0x90

(gdb) set {unsigned char}0x0000555555555224 = 0x2b
```

Zuerst wird erneut der `je`-Sprung mit NOPs überschrieben, um die Passwortabfrage zu umgehen. Anschließend wird der `add`-Opcode an Adresse `0x...5224` durch `0x2b` (`sub`) ersetzt.

| Opcode | Instruktion |
|--------|-------------|
| `0x03` | `add`        |
| `0x2b` | `sub`        |
| `0x90` | `nop`        |
