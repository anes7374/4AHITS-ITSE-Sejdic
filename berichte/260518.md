# 1. Vorbereitung der Übungsumgebung

## 1.1 Analyse des Skripts

Das Skript legt mehrere Gruppen und Benutzer an und erstellt eine kleine Laborumgebung unter `/tmp/lab`.

### Gruppen

```bash
groupadd music
groupadd wrestle
groupadd emperors
```

### User + Gruppenzuweisung

```bash
useradd -m -G music elvis
useradd -m -G music,wrestle blondie
useradd -m -G wrestle hogan
useradd -m -G emperors nero
```

### Passwörter setzen

```bash
echo "elvis:kali" | chpasswd
```

Alle User bekommen das Passwort `kali`.

### Lab-Verzeichnis

```bash
mkdir -p /tmp/lab/gigs /tmp/lab/drafts
echo "Draft" > /tmp/lab/drafts/lyrics.txt
echo "Plans" > /tmp/lab/wrestle_plans.txt
```

### Rechte setzen

```bash
chown -R root:root /tmp/lab
chmod -R 755 /tmp/lab
```

`755` bedeutet:

| User | Group | Others |
|------|--------|---------|
| rwx | r-x | r-x |

---

## 1.2 Skript ausführen

```bash
chmod +x setup.sh
sudo ./setup.sh
```

# 2. Übung (Analyse und Symbolic Mode)

## 2.1 Rechte auslesen

```bash
──(kali㉿kali)-[~]
└─$ ls -l /tmp/lab/wrestle_plans.txt 
-rwxr-xr-x 1 root root 6 May 18 06:36 /tmp/lab/wrestle_plans.txt
 
```
- User Owner: `root`
- Group Owner: `root`
- Rechte: `rwxr-xr-x`

---

## 2.2 Private Files

```bash
┌──(kali㉿kali)-[~]
└─$ touch notes.txt       
                                                                             
┌──(kali㉿kali)-[~]
└─$ chmod o-r notes.txt
```

Damit verlieren Others das Leserecht.

---

## 2.3 Group Sharing

```bash
┌──(kali㉿kali)-[~]
└─$ chmod u=rwx,g=rw,o= notes.txt 
```

- User → volle Rechte
- Group → lesen + schreiben
- Others → keine Rechte

---

## 2.4 Skript vorbereiten

```bash
┌──(kali㉿kali)-[~]
└─$ touch myscript.sh
                                                                             
┌──(kali㉿kali)-[~]
└─$ chmod ug+x myscript.sh  
```

Dadurch dürfen User und Group das Skript ausführen.

---

## 2.5 Kollektive Änderung

```bash
┌──(kali㉿kali)-[~]
└─$ touch data.txt   
                                                                             
┌──(kali㉿kali)-[~]
└─$ chmod go-wx data.txt  
```

Write- und Execute-Rechte werden für Group und Others entfernt.

# 3. Übung (Ownership und Gruppenkollaboration)

## 3.1 sudoers-Eintrag für blondie

```bash
sudo su
visudo
```

Eintrag:

```bash
blondie ALL=(root) NOPASSWD: /usr/bin/mv, /usr/bin/chown
```

---

## 3.2 Group Change

```bash
┌──(kali㉿kali)-[~]
└─$ su - blondie
Password: 
$ touch song.txt
$ sudo mv song.txt /tmp/lab/
$ chgrp music /tmp/lab/song.txt
$ exit
```

---

## 3.3 Unterschied zwischen su und su -

### su

```bash
┌──(kali㉿kali)-[~]
└─$  su blondie
```

Wechselt nur den User.

### su -

```bash
┌──(kali㉿kali)-[~]
└─$  su - blondie
```

Lädt zusätzlich die komplette Login-Umgebung des Users.

---

## 3.4 User Transfer

```bash
sudo chown elvis /tmp/lab/song.txt
```

Dadurch wird `elvis` Owner der Datei.

---

## 3.5 Wrestler-Szenario

```bash
su - hogan
touch /tmp/lab/training.txt
chgrp wrestle /tmp/lab/training.txt
chmod g=rw,o= /tmp/lab/training.txt
ls -l /tmp/lab/training.txt
```

---

## 3.6 Einschränkungen

```bash
chgrp emperors file.txt
```

Der Befehl funktioniert nicht, weil `elvis` nicht Mitglied der Gruppe `emperors` ist.

# 4. Übung (Directory Permissions und Octal Notation)

## 4.1 Oktale Rechte

```bash
chmod 755 file
chmod 660 file
chmod 700 file
```

---

## 4.2 Pub-Verzeichnis

```bash
mkdir /home/kali/pub
chmod 751 /home/kali/pub
```

Others dürfen das Verzeichnis betreten, aber nicht den Inhalt auflisten.

---

## 4.3 Recursive Lockdown

```bash
chgrp -R music /tmp/lab/drafts
chmod -R 770 /tmp/lab/drafts
```

---

## 4.4 Search Permission

```bash
chmod 711 /home/kali
```

Dadurch können andere User zwar nicht den Inhalt anzeigen, aber bekannte Unterordner betreten.

---

## 4.5 Analyse: chmod -R 660 /tmp/lab/

```bash
chmod -R 660 /tmp/lab/
```

Danach fehlt bei den Ordnern das `x`-Recht.

Ohne Execute-Recht kann man nicht mit `cd` in das Verzeichnis wechseln.
